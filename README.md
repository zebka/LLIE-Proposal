# پروپوزال دکتری: بهبود تصویر کم‌نور گرگ‌ومیش با پیشین مدل‌های انتشار

این پوشه، خط تولید کامل پروپوزال است: از متن خام تا فایل Word و LaTeX نهایی.

## جریان کار (مهم)

**قانون طلایی: فقط `src/*.md` را ویرایش کن؛ فایل‌های Word/LaTeX هیچ‌وقت دستی ویرایش نمی‌شوند.**

```
src/*.md ──► scripts/build_docs.py ──► output/Proposal-Standalone.docx
           │                       └─► latex/main.tex ──► latex/main.pdf
           └─ (و references.bib)
```

دستور تولید (از داخل پوشهٔ `Twilight-LLIE-Proposal`):

```powershell
python scripts\build_docs.py      # Word + LaTeX
python scripts\build_html.py      # صفحهٔ وب RTL (یک فایل خودبسنده)
```

صفحهٔ وب را با دوبار کلیک روی `output/proposal.html` باز کن — به اینترنت نیازی ندارد.
مزیت آن: مشکل قاطی‌شدن متن فارسی/انگلیسی را ریشه‌ای حل می‌کند (`dir="rtl"` + ایزوله‌سازی
`<bdi>` هر رشتهٔ لاتین)، و ارجاعات درون‌متن با کلیک به فهرست مراجع می‌پرند.

برای PDF: پس از تولید `main.tex`:

```powershell
cd latex
xelatex main.tex
xelatex main.tex
```

## نکات

- **افزودن مرجع:** یک مدخل به `references.bib` اضافه کن، در متن با `[کلید]` ارجاع بده — شماره‌گذاری خودکار است.
- **افزودن جدول:** یک مارکر `[[TABLEn]]` در md بگذار و داده‌ها را در دیکشنری `TABLES` فایل `fill_form.py` تعریف کن.
- **نقشهٔ شکل‌ها:** `docs/figures-plan.md` (کدام شکل از کدام مقاله، شماره‌گذاری ۱ تا ۱۶).
- `PhDProposalform-USER-EDITED-BACKUP.docx` در پوشهٔ والد، ویرایش دستی خودت روی فرم را نگه داشته است.
